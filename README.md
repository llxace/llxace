# Hi, I'm llxace 👋

用 Swift 做原生应用，把日常里真实遇到的问题，整理成轻量、实用的小工具。关注本机优先、简单直接的使用体验，也尽量把数据保存方式和项目限制说明白。

## Projects

### [户外装备库](https://github.com/llxace/outdoor-gear-library)
本机优先的徒步装备管理应用。整理装备档案、行前打包和徒步记录；macOS 主应用之外，也提供 Windows、iPhone 和 iPad 工程或预览版本。

[项目介绍页](https://llxace.github.io/outdoor-gear-library/) · [下载与版本](https://github.com/llxace/outdoor-gear-library/releases)

### [轻截图](https://github.com/llxace/qing-jietu)
轻量 macOS 截图工具。框选区域或窗口后直接复制到系统剪贴板，不自动保存截图、不创建历史记录，也不会上传。

[下载最新版本](https://github.com/llxace/qing-jietu/releases/latest)
